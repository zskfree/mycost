# MyCost 苹果快捷指令设置说明

本文档对应当前 MyCost API，实现目标是：通过 Action Button、锁屏组件、轻点背面或 Siri 快速发起记账。推荐文本直录作为主链路，音频上传作为兜底链路。

## 1. 使用前准备

先完成 Cloudflare 部署，并准备：

- Worker 生产域名，例如 `https://mycost.example.com`。
- API 地址：`https://mycost.example.com/api/v1/entry`。
- `APP_PASSKEY`。
- iPhone 已联网。
- iOS 版本支持“听写文本”“获取 URL 内容”“生成 UUID”等快捷指令动作。

不要在快捷指令中填写：

- `ONE_API_KEY`。
- Cloudflare API Token。
- D1 `database_id`。

快捷指令只需要访问 MyCost Worker API，并携带个人 `APP_PASSKEY`。

## 2. API 请求约定

### 2.1 文本请求

```http
POST https://<your-worker-domain>/api/v1/entry
Authorization: Bearer <APP_PASSKEY>
Content-Type: application/json
```

JSON Body：

```json
{
  "request_id": "每次请求新生成的 UUID",
  "text": "听写得到的记账文本",
  "datetime": "2026-09-01T17:15:00+08:00",
  "weekday": "二",
  "source": "shortcuts"
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---:|---|
| `request_id` | 是 | 幂等键。每次新的记账请求生成新 UUID；重试同一请求必须复用原值 |
| `text` | 是 | 听写文本，例如“打车花了 35 元，微信支付” |
| `datetime` | 否 | iPhone 当前本地时间，建议传 ISO 8601 和时区 |
| `weekday` | 否 | 当前星期，用于辅助相对日期解析 |
| `source` | 否 | 固定传 `shortcuts` |

### 2.2 音频请求

```http
POST https://<your-worker-domain>/api/v1/entry
Authorization: Bearer <APP_PASSKEY>
Content-Type: multipart/form-data
```

表单字段：

```text
request_id: 每次请求新生成的 UUID
audio: 录制的音频文件
datetime: iPhone 当前本地 ISO 8601 时间
weekday: 当前星期
source: shortcuts
```

当前后端接受 WAV、m4a 等常见音频文件，并把音频转发到 One API 多模态模型。音频只在请求处理期间使用，不写入 D1。

## 3. 创建文本直录快捷指令

在 iPhone 打开“快捷指令”App：

1. 点击右上角 `+` 新建快捷指令。
2. 将名称改为 `MyCost 记一笔`。
3. 按以下顺序添加动作。

### 3.1 动作一：听写文本

搜索并添加：`听写文本`。

建议设置：

- 语言：中文。
- 停止听写：检测停顿后停止，或手动点击完成。
- 听写结果保存为变量 `听写文本`。

### 3.2 动作二：空文本判断

添加：`如果`。

条件：

```text
听写文本 没有任何值
```

在“如果”分支中添加：

1. `显示通知`：`没有听到记账内容，请重试`。
2. `停止此快捷指令`。

结束“如果”块后继续后续动作。

### 3.3 动作三：生成幂等键

添加：`生成 UUID`。

把输出重命名为变量：`request_id`。

规则：

- 每次新开始一次记账，都必须重新生成 UUID。
- 网络失败后重试同一笔时，不要重新生成 UUID；应复用原 UUID。
- 不同账单不能共用 UUID。

### 3.4 动作四：获取当前时间

添加：`当前日期`，输出变量命名为 `当前日期`。

再添加：`格式化日期`，配置：

```text
输入：当前日期
日期格式：自定
自定格式：yyyy-MM-dd'T'HH:mm:ssXXX
```

输出变量命名为：`datetime`。

如果当前 iOS 版本不接受 `XXX`，使用“ISO 8601”日期格式选项，确保结果类似：

```text
2026-09-01T17:15:00+08:00
```

### 3.5 动作五：获取星期

添加：`格式化日期`，输入仍使用 `当前日期`：

```text
日期格式：自定
自定格式：E
```

中文系统通常得到“周二”或“星期二”。输出变量命名为：`weekday`。

### 3.6 动作六：获取 URL 内容

添加：`获取 URL 内容`。

配置：

```text
URL: https://<your-worker-domain>/api/v1/entry
方法: POST
请求正文: JSON
```

在 Header 中添加：

```text
Authorization: Bearer <APP_PASSKEY>
Content-Type: application/json
```

建议不要把 Token 直接写成可见文字。可以单独添加动作：`询问每次` 或使用快捷指令私有文本变量保存 Token。测试阶段可先直接填写，正式使用时注意不要把快捷指令分享给其他人。

JSON Body 添加：

```text
request_id: UUID 动作输出
text: 听写文本
 datetime: datetime
weekday: weekday
source: shortcuts
```

注意：`datetime` 前不要保留多余空格。上面的 `datetime` 是变量，不是固定字符串。

### 3.7 动作七：读取响应通知

当前 API 成功响应示例：

```json
{
  "status": "SUCCESS",
  "message": "已记入「交通/打车」¥35.00",
  "duplicated": false,
  "transactions": []
}
```

最简单的快捷指令做法：

1. 添加 `获取词典中的值`。
2. 词典选择“获取 URL 内容”的结果。
3. Key 填 `status`。
4. 添加 `如果`：`status 是 SUCCESS`。
5. 成功分支添加 `显示通知`，通知内容使用响应中的 `message`。
6. 失败分支添加 `显示通知`：`记账失败，请检查网络或服务配置`。

推荐通知文案：

```text
成功：直接显示 API 返回的 message
重复请求：已处理：<message>
网络错误：记账失败：网络不可用或服务异常
401：记账失败：APP_PASSKEY 无效
One API 错误：记账失败：AI 解析服务暂不可用
```

测试阶段也可以直接添加 `显示结果` 查看完整 JSON，确认字段后再改成通知。

## 4. 创建音频兜底快捷指令

建议单独创建快捷指令，名称为 `MyCost 语音记一笔`。也可以在文本快捷指令中增加“听写失败后录音”的分支，但单独快捷指令更容易排查。

### 4.1 动作顺序

```text
1. 录制音频
2. 生成 UUID
3. 当前日期
4. 格式化日期为 ISO 8601
5. 格式化日期获取星期
6. 获取 URL 内容
7. 读取 status 和 message
8. 显示通知
```

### 4.2 录制音频

搜索并添加：`录制音频`。

建议设置：

- 录音完成方式：点击停止后继续。
- 最长录音时间：10 秒以内。
- 不要启用会把文件保存到“文件”App 的额外动作。

录音结果直接作为后续请求的 `audio` 文件输入。

### 4.3 配置 multipart 请求

`获取 URL 内容` 配置：

```text
URL: https://<your-worker-domain>/api/v1/entry
方法: POST
请求正文: 表单
```

Header：

```text
Authorization: Bearer <APP_PASSKEY>
```

不要手工把 `Content-Type` 写成固定的 `multipart/form-data` 并自行拼 boundary。让“获取 URL 内容”动作自动生成 boundary，否则服务端可能无法解析文件。

表单字段：

```text
request_id: UUID 动作输出
audio: 录制音频动作输出
datetime: ISO 8601 当前时间
weekday: 星期输出
source: shortcuts
```

音频请求不能只传 `audio` 而不传 `request_id`。没有幂等键，网络重试可能导致重复入账。

## 5. 绑定四种触发方式

### 5.1 Action Button

适用于支持操作按钮的 iPhone Pro：

1. 打开“设置”。
2. 进入“操作按钮”。
3. 滑动到“快捷指令”。
4. 选择 `MyCost 记一笔`。
5. 长按 Action Button 测试听写。

如果要把音频作为独立兜底入口，选择 `MyCost 语音记一笔`；不要让两个快捷指令同时绑定同一个按钮。

### 5.2 锁屏组件

1. 锁屏长按空白处。
2. 点击“自定”。
3. 选择“锁定屏幕”。
4. 点击组件区域。
5. 添加“快捷指令”组件。
6. 选择 `MyCost 记一笔`。
7. 点击“完成”。

### 5.3 轻点背面

1. 打开“设置”。
2. 进入“辅助功能”。
3. 进入“触控”。
4. 滑到页面底部，进入“轻点背面”。
5. 选择“轻点两下”或“轻点三下”。
6. 选择 `MyCost 记一笔`。

建议只绑定一种轻点次数，避免误触造成重复请求。

### 5.4 Siri

快捷指令名称使用短且唯一的中文，例如 `记一笔`：

```text
嘿 Siri，记一笔
```

Siri 启动后，快捷指令执行“听写文本”。如果 Siri 抢先结束听写，改用 Action Button 或锁屏组件测试。

## 6. 测试用例

### 6.1 单笔文本

说：

```text
中午吃牛肉面 28 块，微信支付
```

预期：

- 通知包含 `已记入`。
- 分类为餐饮，二级分类通常为午餐。
- 金额为 `¥28.00`。
- 查询接口中 `amount_cents` 为 `2800`。

### 6.2 多笔文本

说：

```text
买咖啡 18，晚上超市买菜 65
```

预期：

- API 返回 2 笔交易。
- 通知总金额为 `¥83.00`。

### 6.3 相对日期

在周二测试：

```text
昨天打车花了 32
```

预期交易日期为周一，不能使用服务器 UTC 日期替代客户端时间。

### 6.4 音频兜底

录音内容：

```text
今天停车 20 元
```

预期：

- 请求成功返回通知。
- D1 新增一笔交通/停车记录。
- 音频不会出现在交易表中。

### 6.5 重试和幂等

测试方法：

1. 保存一次请求使用的 `request_id`。
2. 用相同 `request_id` 再发送相同请求。
3. 查询交易列表。

预期：

- 第二次响应中的 `duplicated` 为 `true`。
- 数据库不新增第二笔。

### 6.6 网络和鉴权错误

分别测试：

- 关闭网络后执行：应显示网络失败通知。
- 修改一个字符的 `APP_PASSKEY`：应返回 `401`。
- 临时关闭 One API：应显示 AI 服务失败，不应产生半条账单。

## 7. 常见问题

### 返回 401

检查：

- Header 是否为 `Authorization`。
- 值是否严格为 `Bearer ` 加 Token，中间有一个空格。
- Token 是否和 Cloudflare Worker 生产环境的 `APP_PASSKEY` 完全一致。
- 是否请求了正确的 Worker 域名。

### 返回 400 且提示 text required

说明 JSON 请求没有传有效 `text`。检查“听写文本”输出是否为空，以及 JSON Body 中 `text` 是否绑定了变量而不是普通文本。

### 返回 One API env missing

说明 Cloudflare Worker 没配置 `ONE_API_BASE_URL`、`ONE_API_KEY` 或 `MULTIMODAL_MODELS`。检查 Production 环境变量，并重新部署。

### 文本成功、音频失败

检查：

- One API 模型是否支持 `input_audio`。
- 音频表单字段名称是否是 `audio`。
- 请求正文是否是“表单”。
- 是否手工覆盖了 multipart boundary。
- 录音文件大小是否过大。

### 通知成功但列表没有记录

先点击 PWA 刷新，再调用：

```text
GET https://<your-worker-domain>/api/v1/transactions?month=YYYY-MM
```

如果查询仍没有记录，查看 Cloudflare Worker 日志和 D1 远端数据。
